# 1. Obiettivo

La Hero Section rappresenta il primo elemento visualizzato
dal visitatore.

Ha il compito di comunicare immediatamente:

- identità professionale
- competenze
- valore offerto
- invito all'azione

La Hero deve risultare moderna,
pulita,
veloce
e altamente professionale.
