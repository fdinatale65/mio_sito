# UX

Questa cartella contiene la documentazione relativa all'esperienza utente (User Experience) del portfolio.

## Contenuto

- User Journey
- Visual Identity
- Responsive Strategy
- Interaction Guidelines
- Accessibility Guidelines

## Obiettivo

Definire le regole che guidano la progettazione dell'interfaccia e l'esperienza di navigazione.

Tutti i documenti presenti in questa cartella costituiscono il riferimento ufficiale per la progettazione UX del progetto.
