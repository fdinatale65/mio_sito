# 1. Obiettivo

Questo documento definisce la libreria ufficiale dei componenti grafici del portfolio.

Ogni componente dovrà essere riutilizzabile, coerente con il Design System e facilmente manutenibile.

L'obiettivo è garantire uniformità visiva e ridurre il tempo necessario per la realizzazione di nuove pagine.

---

# 2. Principi

Ogni componente dovrà essere:

- riutilizzabile;
- responsive;
- accessibile;
- documentato;
- coerente con il Color System;
- coerente con il Typography System.
