# 1. Obiettivo

Questo documento definisce gli standard relativi alle icone, alle immagini, ai loghi e a tutte le risorse grafiche utilizzate all'interno del portfolio.

Lo scopo è garantire uniformità visiva, elevate prestazioni e una gestione centralizzata degli asset.

---

# 2. Principi

Tutti gli asset dovranno essere:

- coerenti;
- ottimizzati;
- riutilizzabili;
- facilmente identificabili;
- organizzati.

---

# 3. Icone

Libreria principale

```
Font Awesome
```

Supporto

```
Elementor Icons
```

---

# 4. Stile delle Icone

Le icone dovranno essere:

- lineari;
- semplici;
- moderne;
- facilmente riconoscibili.

Evitare icone troppo elaborate.

---

# 5. Dimensioni

Icone piccole

```
16 px
```

---

Icone standard

```
24 px
```

---

Icone Hero

```
40–48 px
```

---

# 6. Colori

Colore predefinito

Dark Gray

Hover

Primary Blue

Active

Accent Blue

Le icone dovranno rispettare il Color System definito nel documento DESIGN-001.

---

# 7. Logo

Versioni previste

- Logo principale
- Logo monocromatico
- Logo per sfondi scuri
- Favicon

Tutte le versioni dovranno essere archiviate nella cartella dedicata agli asset.

---

# 8. Immagini

Tipologie

- fotografia personale;
- screenshot;
- mockup;
- immagini dei progetti;
- immagini illustrative.

---

# 9. Formati

Immagini

```
WebP
```

Compatibilità

```
PNG
JPEG
```

Icone vettoriali

```
SVG
```

---

# 10. Ottimizzazione

Ogni immagine dovrà essere:

- compressa;
- ridimensionata;
- priva di metadati non necessari.

---

# 11. Naming Convention

Esempi

```
hero-profile.webp

project-conversione-db.webp

technology-python.svg

logo-fdn-dark.svg
```

Utilizzare:

- lettere minuscole;
- parole separate da trattino;
- nomi descrittivi.

---

# 12. Screenshot

Gli screenshot utilizzati nella documentazione dovranno:

- essere aggiornati;
- mostrare l'interfaccia completa;
- utilizzare una risoluzione adeguata.

---

# 13. Repository Images

Le immagini dei progetti dovranno includere:

- homepage;
- dashboard;
- diagrammi;
- schermate significative.

---

# 14. Favicon

Dimensioni consigliate

```
32×32

48×48

180×180
```

---

# 15. Social Preview

Predisporre immagini dedicate per:

- LinkedIn;
- GitHub;
- Facebook;
- X.

Dimensione consigliata

```
1200 × 630 px
```

---

# 16. Open Graph

Ogni pagina importante dovrà prevedere:

- immagine Open Graph;
- titolo;
- descrizione.

---

# 17. Gestione Asset

Gli asset dovranno essere organizzati nelle seguenti categorie.

```
Logo

Icons

Screenshots

Projects

Profile

Social

Mockups
```

---

# 18. Backup

Tutti gli asset originali dovranno essere conservati.

Le versioni ottimizzate saranno utilizzate nel sito.

---

# 19. Evoluzione

L'introduzione di nuovi asset dovrà rispettare gli standard definiti in questo documento.

Eventuali nuove categorie dovranno essere documentate.
