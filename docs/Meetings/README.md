# Meetings

Questa cartella raccoglie gli appunti e i verbali delle sessioni di progettazione e sviluppo del sito.

## Contenuto

Ogni documento descrive:

- obiettivi della sessione
- decisioni progettuali
- modifiche concordate
- attività completate
- attività pianificate
- eventuali problemi riscontrati

## Convenzione

Formato consigliato:

YYYY-MM-DD_<Titolo>.md

Esempi:

2026-08-23_Repository_Refactoring.md

2026-08-28_Home_Page_Review.md

2026-09-02_SEO_Optimization.md
