Questa sezione rappresenta il cuore tecnico del portfolio.

# 4. Aree di competenza

## Backend Development

Progettazione e sviluppo di applicazioni backend scalabili.

Competenze principali

- Python
- PHP
- Node.js
- REST API
- OOP
- MVC

---

## Database Engineering

Progettazione, gestione e migrazione di basi dati.

Competenze

- MySQL

- SQL Server

- PostgreSQL

- Query Optimization

- Data Migration

---

## Software Architecture

Progettazione di architetture software.

Competenze

- Domain Driven Design

- Layered Architecture

- Clean Code

- Repository Pattern

- Dependency Injection

---

## System Administration

Gestione di sistemi Windows e Linux.

Competenze

- Windows Server

- Active Directory

- Backup

- Virtualizzazione

- Networking

---

## WordPress Development

Realizzazione e personalizzazione di siti WordPress.

Competenze

- Astra

- Elementor

- Child Theme

- WooCommerce

- Performance

---

## AI Assisted Development

Utilizzo dell'intelligenza artificiale per accelerare lo sviluppo software.

Ambiti

- ChatGPT

- Codex

- Prompt Engineering

- Technical Documentation

- Software Design
