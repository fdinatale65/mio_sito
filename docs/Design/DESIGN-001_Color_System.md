# 1. Obiettivo

Il presente documento definisce il sistema cromatico ufficiale del portfolio.

Ogni componente grafico dovrà utilizzare esclusivamente i colori descritti in questo documento.

Lo scopo è garantire uniformità, riconoscibilità e coerenza visiva.

---

# 2. Principi

La palette dovrà trasmettere:

- professionalità
- tecnologia
- affidabilità
- pulizia
- modernità

Sono da evitare colori eccessivamente saturi o effetti grafici invasivi.
